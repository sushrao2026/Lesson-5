# My Links — Link-in-bio

Simple static link-in-bio page built with plain HTML, CSS, and JavaScript.

Deploy to Vercel: just connect this repository and deploy as a static site. Ensure `index.html` is at the root.

Files:
- index.html — single page
- styles.css — styles
- script.js — theme toggle and small interactions

Notes:
- Uses Google Font `Inter`.
- Dark mode is default; toggle persists in `localStorage`.
- Replace `avatar-placeholder.png` with your profile photo (120x120 recommended).
